# Saccade Web Application

This directory will house the **Next.js 15 (App Router) + Tailwind CSS** frontend in Phase 2.

### Planned Features:
- **Interactive Dual-Pane Studio**: Real-time PDF preview powered by `pdf.js` on the right; chat & tailoring controls on the left.
- **Embedded AI Chat**: Directly connected to the Saccade Agent Core (`interfaces/api`).
- **Visual Theme & Typography Customizer**: Margin, font, and color controls that compile into LaTeX themes without touching raw TeX code.
- **Supabase Authentication**: User logins, master profile sync, and versioned application history.
